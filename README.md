# Banshee and Black Rose Arcade

A small browser arcade for The Banshee Labyrinth and The Black Rose Tavern, Edinburgh.

- **Old Town Quest**: travel a map of the Old Town, find an item at each place, solve the riddle door and unlock the story of that place.
- **Cellar Ghost**: a platform game through the cellars.
- **Labyrinth Chase**: endless mazes that get trickier every level.
- **Story Book**: the true and legendary stories found along the way. Anything marked legend is folklore, not proven history.

Single static page, no build step. Scores and found stories are saved on the player's own device.

Map data: (c) OpenStreetMap contributors.
